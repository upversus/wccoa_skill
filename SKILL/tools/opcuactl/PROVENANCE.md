## Зачем он в скилле

У скилла не было инструмента для OPC UA: эмулятора нет, а без него нельзя
доказать, что адрес работает. `opcuactl` закрывает половину этой дыры — он
умеет находить серверы и обходить их пространство имён:

```
discover endpoints    найти сервер и его endpoint'ы
browse children       обойти узел и получить потомков
find                  искать по имени и по namespace
get                   прочитать значение, атрибуты, состояние сервера
write                 записать значение
monitor               подписаться на изменения
history               читать историю
export                выгрузить данные
call                  вызвать метод
ping                  проверить связь
```

Это ровно тот механический шаг, которого не хватало: по выводу `browse`
строится карта адресов, дальше она разбирается так же, как карта Modbus.

## Что проверено на стенде

Kepware KEPServerEX V6, анонимный доступ, драйвер OPC UA номер 3.

| Команда | Результат |
| --- | --- |
| `ping` | связь, 2,1 мс |
| `discover endpoints` | 5 endpoint'ов, анонимный токен разрешён |
| `browse children` от `i=85` | дерево пространства имён |
| `get value` | значение, тип, статус |
| `get attr --all` | 22 атрибута узла |
| `get vars --recursive -f json` | 4085 переменных, 962 КБ |
| `monitor value -f json` | поток изменений, использован для сверки с OA |

Сверка данных: точка WinCC OA и `monitor value` запущены одновременно,
значения сравнены по временны́м меткам. Темп совпал, расхождение росло
линейно, то есть это задержка опроса. Подробно в
`playbooks/opcua-addressing.md`.

## Чего он НЕ делает

**Разбор карты в адреса WinCC OA не написан.** Обход отдаёт данные, но
готового генератора нет: формат адреса OPC UA и коды типов другие, чем у
Modbus.

**Проверка записи в OPC UA не сделана.** Для Modbus запись подтверждается
запросом на устройстве; здесь такого подтверждения нет.

## Замена пути к инструменту

По умолчанию `opcuactl.exe` ищется рядом с плейбуками. Если инструмент
установлен отдельно, путь задаётся переменной окружения:

```powershell
$env:OPCUACTL = 'C:\путь\к\opcuactl.exe'
```

## Обновление

Двоичный файл заменяется целиком, проверяется версия:

```powershell
& .\tools\opcuactl\opcuactl.exe version
```

При замене на новую версию обязательно синхронизируй этот файл: версию,
commit и текст `LICENSE` из новой версии репозитория.
