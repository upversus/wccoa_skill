# wccoa_skill

Скилл для WinCC OA 3.18: проверенные функции точек данных из CTL, примеры
и инструменты. Всё содержимое проверено запуском на живом проекте, а не
переписано из документации.

Рабочая часть репозитория — каталог [`SKILL/`](SKILL/README.md). Это
автономная папка: её можно скопировать целиком в каталог скиллов, пути
внутри относительные.

## Состав

| Путь | Что это |
| --- | --- |
| `SKILL/SKILL.md` | входная точка скилла: правила работы и индекс задач |
| `SKILL/docs/` | справочник по операциям CTL с измеренными оговорками к документации |
| `SKILL/examples/` | 84 примера CTL по этапам и гейт `verify.ps1` |
| `SKILL/playbooks/` | четыре пошаговых сценария задач |
| `SKILL/tools/` | эмулятор Modbus, генераторы CTL, валидатор, `opcuactl` |

Разделы справочника: создание, конфигурация, чтение, запись, подписки,
запросы, копирование, тревоги, удаление, периферийные адреса Modbus/OPC UA,
сопоставление карты адресов с CTL, HTTP-клиент `net*` и JSON/mapping
(`legacyFoo`).

## Проверка

```powershell
cd SKILL
.\examples\verify.ps1 -All
```

Полный гейт прогоняет 51 скрипт и завершается кодом 0. Раздел `11-address`
(17 скриптов) исключён по умолчанию — ему нужен подготовленный стенд
с эмулятором Modbus и OPC UA; включается ключом `-IncludeAddress`. Раздел
`13-net` (4 скрипта) требует запущенного HTTP-тестового сервера;
включается ключом `-IncludeNet`. Гейт всегда сообщает, сколько скриптов
исключено и почему.

## Требования

| Что | Версия | Обязательно |
| --- | --- | --- |
| WinCC OA | 3.18 | да |
| PowerShell | 5.1 и новее | да |
| Node.js | 18 и новее | для Modbus |
| OPC UA сервер | любой | только для задач OPC UA |

Путь к `WCCOActrl.exe` задаётся переменной `WCCOA_CTRL_EXE`; если она не
задана, используется стандартная установка. Подробности —
в [`SKILL/README.md`](SKILL/README.md).
